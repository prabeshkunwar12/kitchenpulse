# Changelog

## 0.2.0 · Sprint 1 development prototype

- Fixed the Compose build path, added environment templates, isolated PostgreSQL volumes, a loopback bind and health checks.
- Added Alembic, the inventory catalog and a decimal stock ledger with transactional adjustments, request deduplication and linked reversals.
- Added stock counts, independent manual reports, calculated statuses and recommended replenishment.
- Added 27 labeled demo products across nine categories and a PostgreSQL integration suite.
- Integrated the landscape inventory experience, search, filters and history into the Expo tablet app. Added same-request retries and local browser preview support.

## 0.1 · Starter baseline

- FastAPI prototype for inventory creation, stock movement, thresholds, manual low-stock reports, recent history and undo.
- PostgreSQL and Docker Compose starter, plus an Expo scaffold and a separate React Native inventory screen.
- Captured the initial assessment, requirements and development roadmap.
